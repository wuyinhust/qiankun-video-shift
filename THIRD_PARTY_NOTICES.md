# Third-party method notices

This skill combines independently implemented workflow ideas from the following public projects. It does not run their installers and does not bundle their full applications.

- [luozhilzh/video-prompt-reverse](https://github.com/luozhilzh/video-prompt-reverse), MIT: motion-first reverse prompting, faithful/enhanced variants, negative constraints, consistency anchors, and iterative repair concepts.
- [Danyangkk/viral-video-analyze](https://github.com/Danyangkk/viral-video-analyze), MIT: deterministic outer pipeline, twelve viral-moment categories, conservative scoring, vertical emphasis, and anti-flattery analysis.
- [niobium617/prompt-reverse-engineer-skill](https://github.com/niobium617/prompt-reverse-engineer-skill), MIT: deterministic local media signals, shot/keyframe manifest design, and structured prompt compilation concepts.
- [MiniMax-AI/MiniMax-H3 — h3-prompt-writing](https://github.com/MiniMax-AI/MiniMax-H3/tree/main/skills/h3-prompt-writing): authoritative MiniMax H3 prompt modes and output contract. The official skill remains an external dependency and is not rewritten here.

The acquisition, FFmpeg segmentation, manifest validation, unified four-move workflow, and cross-source output contract in this skill are newly implemented for this integration.
