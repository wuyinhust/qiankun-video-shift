# 视听系统与原创制作计划

完整迁移或用户要求装配时读取；纯反推无需加载。

## 系统比镜头活得更久

镜头表保存真实切点。另用 `visual_systems` 描述跨镜持续的字幕、排行榜、证据卡、UI、B-roll、音效和音乐。一个系统记录 `id / role / behavior / event_ids`，行为说明内容、位置、层级以及进入—停留—变化—退出。相互依赖的布局、遮挡和运动一起设计，独立系统可分开。

模型承担人物、物理动作、产品和环境；后期承担准确文字、数据、图形和确定的版式。生成 Prompt 只包含该素材能实现的内容，字幕和动效另给装配指令。

## 语义先于目标秒数

`semantic_events` 保存 `id / source_range_s / function / kind / anchor_id / target_time_s`。`kind` 为 phrase、action 或 clock。

源秒数定位证据，目标锚点定位表现。例如价格卡跟随目标台词中的价格词，回答板跟随答案，不照搬原视频第几秒。目标声音或表演尚未产生时，`target_time_s=null`；有实际对齐数据后写入数值与 `timing_source`。触发、内部运动、停留和退出分开设计。纯视觉作品使用动作或时钟，不额外创建转录服务。

## 替换完整，依赖浅

`replacement_map` 每项记录源角色、目标角色、受影响系统和真实目标事实。换产品时检查人物手持道具、B-roll、UI、字幕、证明、结果板和 CTA。换人物也需检查头像、反打、插画和声音。动作保留论证或喜剧作用，并适配新主体，不机械套原肢体。

源事实原样保留；受影响事实增加 `target_text` 和 `target_request`。删掉源动作使用 `omit=true` 与明确目标请求。改变主体、节奏或终态在 `intentional_deviations` 说明。脚本不会替你补写产品声明或判断改写是否忠实。

## 复用与局部修改

按需要记录 `accepted_assets`：素材路径、哈希、用途、关联 job_ids/system_ids。将已接受的素材显式交给后续执行器。资产存在不等于当前任务选中了它。

| 修改 | 可复用 | 重做 |
|---|---|---|
| 字幕颜色、版式、动效 | 视频、声音和仍适用的对齐 | 组件与渲染 |
| 个别B-roll | 主表演和其他素材 | 被替换素材及其装配 |
| 台词 | 未受影响的段落 | 受影响表演、对齐与事件 |
| 人物/产品 | 仍成立的背景与图形 | 受影响镜头、所有出现位置与真实声明 |

三变式、批量变量只在用户要求实验时追加，每次明确主要变量。先用真实复用需求决定参数，不预先建立全能模板系统。

## 成片交接与验收

交给用户已选择的制作工具：分段素材需求、参考关系、语义事件、系统布局、声音计划、复用清单。此skill不默认安装引擎或提交生成。

源与目标按相应的台词、动作或作用对比。重点看片头钩子、证明出现、转折和结尾；看文字、遮挡、状态连续及音画同步。预览与编码文件分别验收，最终文件需实际播放并完整解码。格式合法、素材完成、预览正确和成片通过各自报告。
