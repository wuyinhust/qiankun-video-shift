# H3：只加载当前模式

只有用户指定H3时读取。先用已安装的官方 `$h3-prompt-writing`：文字/关键帧模式只读base指南，Ref2VA只读ref指南。格式以官方为准；缺少官方skill时先保留通用母版，再按当前授权处理依赖。

| 实际提交关系 | 模式 |
|---|---|
| 文字 | T2VA |
| 首帧 | I2VA |
| 首尾帧 | FL2VA |
| 尾帧 | L2VA |
| 视频/图片/音频作为多模态参考 | Ref2VA |

分析过源视频不等于把它提交给模型。核实当前平台的时长、模式和参考能力，写入capability；每个任务按能力与语义状态拆分。源镜、生成单元和跨镜后期系统是不同边界。单首帧/首尾帧逐镜任务默认不跨源硬切，改成连续镜头需明确目标改编。

脚本从同一事实编译基本格式；最终核对官方字段、对齐行、局部Shot/Picture编号、时间、参考标签及声音分类。关键帧是目标初/末态，不提前写动作结果。所有复制块完整展示；英文重写区，台词/可见文字保留目标语言。

三字段文字不能复制真实波形。原声按audio_plan真实提交参考或装配，unknown不补歌词；fully_copy是请求，不能当输出音频/口型验收。无效参考或能力缺口保留草稿并说明。
