# 牵引挪移规范

本参考只在第四式读取。输入必须是已经完成视觉复核的逐镜事实和第三式的爆款分析。

## 一、还原版

还原版回答“原片成立所必需的内容是什么”。逐镜写：

```text
[时间范围] + [景别/机位] + [主体与状态] + [动作路径] +
[场景/光色] + [摄影机运动] + [声音] + [转场/终态]
```

使用反事实过滤：如果移除某元素后镜头仍然成立，该元素可省略或弱化；主体、关键动作、空间关系、叙事光线和镜头终态通常不可省略。

不要在还原版加入原片没有的电影术语、画质词、导演名字、效果或品牌语言。无法从证据确认的参数写 `unspecified`，不要伪造焦距、帧率或灯具。

## 二、增强版

增强是在还原版上有依据地加强，而非无边界堆词。每镜最多选择一个主要运动意图和一个主要视觉增强方向。

优先增强：

- 运镜的类型、幅度、速度和目标。
- 主体动作的起点、过程、终点与物理连续。
- 光色层次、主体分离度和跨镜一致性。
- 节奏曲线与关键时刻的到达时间。
- 声音的来源、同步点和动态变化。
- 视频专属失败约束：flicker、morphing、identity drift、text drift、jitter、warping、lip-sync mismatch 等。

避免无效堆叠，如同时要求推近、拉远、环绕、快速摇移和固定镜头。抽象词“高级、电影感、震撼”必须转成可观察的构图、光色、运动或声音指令。

## 三、三变式

每个变式只改变一个主变量，其余锚点保持不变：

- **构图变式**：更换景别、机位或主体布局。
- **光影变式**：更换光源方向、软硬、曝光或色彩关系。
- **风格变式**：更换质感与美术语言，但不改变故事和动作。

为每个变式说明“改了什么、没改什么、适合验证什么”。

## 四、一致性锚点

多镜头必须建立：

```yaml
named_subjects:
  SUBJECT_A: <稳定名称与非身份化描述>
original_lock: <外观、服装、材质、比例、固定道具>
style_lock: <2–4 个跨镜重复的光色与质感锚点>
reference_frames: [<关键帧路径>]
```

每个后续镜头都显式包含：

```text
[Original Lock] + [Prev-shot Token] + [本镜新增内容]
```

`Prev-shot Token` 至少说明上一镜终态、主体位置、动作方向、道具状态和光照连续关系。不要只在第一镜定义角色，后续靠隐含继承。

## 五、爆款公式如何进入提示词

爆款分析约束信息结构，不直接变成画质形容词：

- `hook` 决定第一生成单元最先出现的视觉/语言事件。
- `curiosity_gap` 决定延迟揭示的信息。
- `pain_point` / `relatability` 决定观众可认领的具体处境。
- `authority` / `social_proof` 只能使用用户已验证的事实。
- `super_effect` / `transformation` 决定可见的结果和状态变化。
- `twist` 决定预期翻转点。
- `value` 决定信息密度。
- `urgency` / `cta` 只能使用合规、真实的行动信息。

复刻结构时替换人物、品牌、文案、音乐和独有视觉资产，保留节奏与论证功能。

## 六、生成单元

先按目标模型的时长与镜头能力，把原视频划分为独立生成单元。每个单元：

- 有明确起始状态和结束状态。
- 有一个主要动作或叙事功能。
- 通常不混入超过一个复杂转场。
- 能单独重生与验收。
- 与前后单元通过一致性锚点连接。

MiniMax H3 单元按 4–15 秒组织，并交给官方 H3 Skill 编译。不要把一条长视频强塞进单个 H3 Prompt。

## 七、通用母版输出

通用母版至少包含：

1. 总时长、画幅和总体风格。
2. 按时间排列的逐镜描述。
3. 主体、场景、动作、摄影机、光色和声音。
4. 一致性锚点。
5. 负向约束。
6. 原创替换说明。

目标模型版本应从母版编译，不重新观察视频或重新发明分析结论。
