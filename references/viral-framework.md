# 寻瑕抵隙框架

本参考只在第三式读取。目标是解释“结构为何可能有效”，不是根据画面臆测真实流量。

## 先区分事实与潜力

- 有真实播放、完播、互动、转化数据：可以分析实际表现，但标明数据来源。
- 只有视频：使用“结构潜力评分”，不得说“已经爆了”“完播率很高”或虚构指标。
- 评分 0–10，8 分以上需要多项强证据，9 分以上只用于现象级结构。

## 十二种关键时刻

| 组别 | 主类型 | 相关类型 | 判定问题 |
|---|---|---|---|
| 抓人 | `hook` | `curiosity_gap` | 它让人停下，还是让人必须知道答案？ |
| 代入 | `pain_point` | `relatability` | 它呈现问题，还是让观众认领熟悉场景？ |
| 背书 | `authority` | `social_proof` | 是“我有资格说”，还是“别人也认可”？ |
| 效果 | `super_effect` | `transformation` | 是瞬间奇观，还是前后状态转变？ |
| 节奏 | `twist` | `urgency` | 是打破预期，还是催促立即行动？ |
| 价值 | `value` | `cta` | 是提供收获，还是明确下一步动作？ |

每条关键时刻：

- 位于一个明确 `[start_s, end_s]` 区间，通常 0.5–8 秒。
- 具有一个主类型，可选一个副类型。
- `description` 只写客观发生了什么。
- `mechanism` 解释用户心理和内容设计如何共同作用。
- `evidence_shots` 指向支撑它的镜头编号。
- `score` 表示该片段对结构潜力的贡献，不代表平台真实数据。

若存在钩子，它通常应落在前 0–5 秒。关键时刻按时间排序；同类型不要无意义重叠，也不要强求凑齐十二种。

## 宏观结构

从以下结构中选择最接近的一种，也允许写“混合结构”：

- 三段式：冲突/问题 → 展开 → 解法。
- 反转式：顺向预期 → 颠覆。
- 教程式：问题 → 步骤 → 结果。
- 对比式：Before → 证据 → After。
- 故事化：角色 → 欲望/阻碍 → 变化。
- 测评式：试用 → 证据 → 判断。
- 情绪宣泄式：共鸣触发 → 情绪升级 → 释放。

## 爆款公式写法

公式必须是一句话，包含 3–5 个可执行结构件：

```text
[钩子形式] + [代入/悬念机制] + [证明或价值] + [高潮/转变] + [收束或 CTA]
```

禁止写“内容好、节奏快、画面高级”这类不可执行结论。每个结构件都要能回指关键时刻和镜头证据。

## 可迁移模式

迁移：

- 开场的信息落差、视觉冲突和提问方式。
- 镜头长度、切点、节奏曲线和信息顺序。
- 痛点→证据→结果的论证结构。
- 可信度装置、反转位置、价值密度和 CTA 时机。

不可照搬：

- 原视频、人物身份、Logo、水印、字幕原文、音乐、台词、独有角色和受保护素材。
- 未经验证的商品功效、销量、数据、资质或用户证言。
- 会让观众误以为与原品牌或创作者有关联的识别元素。

## 品类侧重

- 美妆：痛点、效果可信度、前后对比和滤镜风险。
- 美食：第一口时机、质感声音、视觉诱因和具体指引。
- 知识：好奇缺口、权威来源、信息密度和收藏价值。
- 电商：社会证明、价格锚、紧迫性和合规 CTA。
- 情绪：关系建立、共鸣、情绪曲线和反转。
- 3C：测试方法、硬指标、体验差异和竞品对照。
- 时尚：场景代入、换装转变和可复制搭配公式。

## 反爆款检查

无论评分多高，都给 2–4 条具体隐忧，例如：

- 证据不足或效果可能由滤镜、剪辑造成。
- 人群过窄，跨圈传播弱。
- 信任建立薄或信息来源不明。
- 套路过熟，重复投放易疲劳。
- 医疗、食品、教育、金融或广告声明存在合规风险。
